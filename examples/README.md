# Ejemplos / Examples

| Archivo | Descripción |
|---|---|
| `run_monte_carlo_demo.py` | Simulación Monte Carlo reproducible con la API (sin GUI) y guardado de `experiment_config.json`. |
| `run_cat_demo.py` | Sesión CAT paso a paso con un examinado simulado. |
| `item_bank_example.csv` | Banco de ítems de ejemplo con todas las columnas admitidas (datos de ejemplo, no reales). |

Ejecución desde la raíz del repositorio: `python examples/run_monte_carlo_demo.py`.
